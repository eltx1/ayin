## Current Phase4E — TV focus identity hardening

**Start:** accepted/deployed main `1b864a3949fe10fa99aa58b80e130db26bd35e5b`. **Branch/PR:** `web-pwa-phase-4e-tv-focus-identity`, #149. **Reviewed implementation head:** `14ba142e7449b18594b5ac7355600ed5b4d305eb`. Ending merge/deployment is pending final documentation-head checks.

**Finding:** repeated semantic `data-tv-focus-id` values are legitimate when the same media appears in multiple rows, but the previous geometry adapter passed those duplicate IDs directly to `findNextFocusTarget`. The helper then resolved the first duplicate as current and filtered all same-ID targets. Saved focus was equally ambiguous.

**Change:** `TvFocusScope` now derives occurrence-aware runtime identities while leaving semantic element attributes untouched. Named unique targets keep stable persistence; duplicates persist an occurrence-aware key; unnamed targets receive local geometry IDs only. Legacy raw sessionStorage values resolve as before, and an occurrence-aware saved key falls back to the same semantic target if later data leaves only one copy. Focused dialogs remain isolated geometry scopes. No route, permission, API, schema, provider or native fork changes.

**Regression coverage:** pure tests cover duplicate uniqueness, legacy compatibility, duplicate-to-unique recovery and unnamed targets. Browser acceptance mutates two real Viewer navigation links to the same semantic focus ID in different rows, focuses the lower duplicate and proves ArrowRight selects the lower aligned target instead of the first row. The pre-documentation implementation head passed browser36722717646, security36722719047, inventory36722717544 and quality36722717729.
