## Accepted Phase4E — duplicate-safe TV focus identity

Focused dialogs remain isolated geometry scopes. No API, schema, permission, ownership, provider or native fork changed.

**Regression and database evidence:** pure tests cover duplicate uniqueness, legacy compatibility, duplicate-to-unique recovery and unnamed targets.
