## Accepted Phase4E — duplicate-safe TV focus identity

**Finding and change:** repeated semantic `data-tv-focus-id` values are legitimate when the same media appears in multiple rows, but the previous geometry adapter passed duplicate IDs directly to `findNextFocusTarget`, causing the first DOM occurrence to masquerade as the current target. `TvFocusScope` now derives occurrence-aware runtime identities while leaving semantic attributes untouched. Unique named targets keep stable persistence, duplicate targets persist occurrence-aware keys, legacy raw session values still resolve, and a saved duplicate occurrence falls back to the semantic target if later data leaves one copy. Modal geometry containment is preserved. No API, schema, permission, ownership, provider, native or product-data change.

**Validation:** pure tests cover duplicate uniqueness, stable unique persistence, legacy compatibility, duplicate-to-unique recovery and unnamed targets.
