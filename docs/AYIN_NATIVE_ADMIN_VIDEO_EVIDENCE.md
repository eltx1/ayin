# Native Admin video workspace — prepared source and acceptance scope

This slice replaces the remaining prompt-based Admin video page with native English/Arabic forms. It depends on the separately reviewed video write authority and deterministic TV preference authority. It does not close any master phase or certify native devices, providers, advertising delivery, or production media.

## Read and command behavior

- A real 25-record directory uses verified Content Moderator/Admin/Operations identity before and after a bounded 15-second read. Finance is denied before any private video request. Real Clip/processing/private/null dates, comment/report counts, and the actual selected TV destination are retained; unrelated preference order is never used as the selected destination.
- Reasons and actual modified metadata fields are retained independently per ID across paging and manual reads. Untouched fields rebase to verified fresh facts, including comments changed by a bulk command. A known acknowledgment clears only the submitted reason and modified-field set. It is retained when a later directory read fails.
- A single command captures the original video version and, when inclusion changes, the actual TV ID and explicit preference version or real default/null state. Bulk commands capture every selected original ID/version, accept only a complete matching acknowledgment, and use an independent reason. Each write has a whole 30-second bound and the server's current actor, MFA, step-up, target locks, atomic audit and rollback checks.
- Lost/malformed/stale responses retain intent and lock further commands. Original-target recovery reads up to four concurrently within one 15-second budget, verifies the actor before/after, preserves real missing404, and discards partial recovery on failure. The operator must read the original targets, explicitly refresh the directory, and complete review before a new command. There is no automatic replay or post-write read and no claim that individual recovery reads share one atomic database snapshot.
- Exact step-up cancellation retains intent without replay. Other identity/role denial clears private facts and intent. The entire private wrapper, including metadata and both reasons, is hidden synchronously before React state updates on pagehide/hidden visibility. A pageshow does not read or write. Volatile draft retention is not memory-erasure certification or installed-device proof.
- Forms use existing design-system components, logical RTL layout, dir=auto for entered text, UTC facts, disclosures and 44px checkbox labels. Removal remains terminal; no nonexistent TV destination or complete owner record is manufactured from a smaller command acknowledgment.
- Editors are mounted only for explicitly opened video disclosures. Open state and independent drafts survive paging/manual reads; unopened records do not mount title/description/status/reason forms. Bulk reason/actions appear only after actual selection or retained bulk intent. This simplifies the directory without hiding recovery or discarding intent; no field-performance improvement is claimed without measurement.
