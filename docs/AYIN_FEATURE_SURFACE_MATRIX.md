## Design and recovery invariants

Reuse [the accepted shared design system](AYIN_DESIGN_SYSTEM.md): one route main/h1, logical RTL layout, native labeled controls, truthful states, accessible scoped tables/disclosures and actual-data metrics. Keep route-scoped EN/AR resources instead of expanding unrelated bundles. No public developer control or implementation narrative is added to ordinary consumer flows.

An acknowledged mutation remains saved even if its next read fails. A network/timeout/server/malformed acknowledgment is uncertain and must not trigger an automatic write replay. Preserve drafts and known root IDs; explicit read review precedes another action. Native dialogs cannot grant server permission. Filtering a bounded snapshot is not global search; UI pagination is not DB pagination unless the actual API implements it.
